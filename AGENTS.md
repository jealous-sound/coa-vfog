# AGENTS.md

CoAVolFog is a Win32 Direct3D 9 volumetric fog and water DLL for the Ascension/CoA WoW 3.3.5a (12340) client. A
`version.dll` proxy loads `CoAVolFog.dll`, which wraps Direct3D 9, retargets a few engine call sites, reshades the
client's water after its liquid pass and draws the fog after the world. It is built with CMake and MSVC; the shaders
are compiled with `fxc`. `README.md` holds the design and the reverse-engineering evidence.

## Agent rules

- Configure once with `cmake -S . -B build -G "Visual Studio 17 2022" -A Win32`, build with
  `cmake --build build --config Release`, test with `ctest --test-dir build -C Release --output-on-failure`
  (the D3D9 harness and the comment check).
- Formatting follows `.editorconfig`: UTF-8, max 120 cols, trailing newline, no trailing whitespace, 4-space indent
  (tabs forbidden).
- Express intent through names, structure and tests; do not add explanatory comments or docstrings in C++, HLSL,
  Python or CMake. Name engine addresses, offsets and constants after what they are, and split code into named
  functions instead of commenting blocks. Preserve legal notices and tool directives. `python tools/check_comments.py`
  enforces this. The comments in `CoAVolFog.ini` are the players' settings documentation and stay.
- Client addresses target the 12340 image (timestamp `0x4C2452FE`). Verify the bytes of a call site before patching
  it, and record the disassembly evidence in `README.md`, not in code.
- Add a harness check in `tests/harness.cpp` for a meaningful behaviour change; a regression should fail before the
  fix and pass after it. Harness checks do not establish in-game behaviour; say so when reporting.
- `data/fogdata.bin` is generated by `tools/convert_classic_fog.py` from the WoW Forever fog and lighting kit (folder
  or zip), placed by the `Light` and `ZoneLight` records of the previous `fogdata.bin` (or of the Classic client's CSV
  exports), which the kit could not decrypt; regenerate it rather than editing it. `data/waterdata.bin` is generated
  by `tools/convert_forever_water.py` from the WoW Forever water kit (folder or zip) in the same way.
- Ask before launching the game client. Install only when the owner says the client is closed: check that no process
  runs from the client folder and that the installed `CoAVolFog.ini` still matches the repository, then replace
  `version.dll`, `CoAVolFog.dll`, `CoAVolFog.ini`, `fogdata.bin` and `waterdata.bin`. After an owner test, read
  `CoAVolFog.log` in the client folder.
- Keep plans and results in the conversation. Routine edits need no backups, receipts or standalone reports; use Git.

## Repository layout

- `proxy/` — the `version.dll` loader that forwards to the system copy.
- `src/` — `d3d9_wrap` (device wrapper, INTZ depth), `msaa_depth` (multisampled depth copy into INTZ: NVAPI, RESZ,
  self-test), `hooks` (call-site thunks), `engine` (client addresses and frame inputs), `engine_actors` (unit walk
  for water contacts), `fog_data` (Classic fog data), `fog_model` (layer parameters), `renderer` (passes),
  `fullscreen_triangle` (the triangle every full-screen pass draws, its edges outside the viewport),
  `transparent_fog` (linear stock fog fitted to the volumetric fog for see-through models after the early composite),
  `overlay` (ImGui settings window: input chaining, drawing at `Present`), `settings_panel` (its widgets), `config`,
  `log`, `status_log`; water: `water_data` (Forever presets, FFT tiles, foam masks), `water_classify` (liquid
  classes), `water_spectrum` and `water_fft` (GPU FFT waves), `water_contacts` (contact tracker, ring impulses at the
  client's ripple events), `water_ripples` (ripple map simulation), `client_ripple_sprites` (hold on the client's
  `waterRipples` splash and wake sprites), `water_renderer` (copies, stencil tagging, shading); look: `forever_look`
  (Forever glow byte before the fog composite, grading decisions at world done and frame end), `grading_renderer`
  (colour grading pass).
- `shaders/` — the ps_3_0 passes: `vf_*` fog (march, temporal, composite and its multisampled silhouette split, god
  rays and their late composite after an early one, depth probe and depth-copy check), `vw_*` water (FFT, ripple
  step, depth copy, shading) and `vp_grade` (colour grading).
- `tests/harness.cpp` — the offline D3D9 harness; `--scene harbour` renders a logged in-game frame, `--scene ripples`
  units wading through the basin. `tests/shaders/` holds a copy of the client's M2 fog shader for the transparent fog
  checks.
- `tools/` — the Classic fog and Forever water data converters and the comment check.
